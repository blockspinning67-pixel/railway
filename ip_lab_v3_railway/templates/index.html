Public IP Lab

This is a cybersecurity training page used to demonstrate what information a web server can receive during a visit.

What happens if you agree?
  • Your public IP address will be recorded.
  • The time of the test will be recorded in UTC.
  • The record will be visible to the lab administrator.
  • Records are automatically deleted after the configured retention period (default: 30 days).

This application does not save your IP address in its lab database unless you actively select the consent option and submit it. The hosting provider may separately process connection metadata to operate and secure the website.

If you do not agree, simply leave this page. No test visit record will be created.
